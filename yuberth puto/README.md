# Paradise Nursery - Shopping Cart

Aplicación React de una tienda de plantas con carrito de compras.

## Tecnologías

- React
- Redux Toolkit
- React Redux
- Vite
- GitHub Pages

## Instalación

```bash
npm install
npm run dev
```

## Despliegue

```bash
npm run deploy
```
